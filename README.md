# Biblioteca Saber Digital

## Descripción

Biblioteca Saber Digital es una aplicación web desarrollada para gestionar un catálogo de libros de manera sencilla, moderna y responsiva.

El proyecto fue desarrollado utilizando Programación Orientada a Objetos en JavaScript y Bootstrap 5 para garantizar una experiencia visual profesional.

## Tecnologías Utilizadas

- HTML5
- CSS3
- JavaScript ES6
- Bootstrap 5
- Programación Orientada a Objetos (POO)

## Funcionalidades

- Visualización de libros
- Búsqueda por título o autor
- Registro de nuevos libros
- Estadísticas automáticas
- Diseño responsivo
- Interfaz moderna negro y dorado
